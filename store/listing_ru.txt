QRow: QR-сканер в таблицу

КРАТКОЕ ОПИСАНИЕ (до 80 символов)
Сканируйте QR-коды и собирайте данные в таблицу с экспортом в Excel

ПОЛНОЕ ОПИСАНИЕ (до 4000 символов)
QRow превращает камеру телефона в быстрый сборщик данных. Наводите на QR-коды, а приложение само складывает всё в аккуратную таблицу, которую можно выгрузить в Excel одним нажатием.

Подходит для инвентаризации, учёта оборудования и товаров, регистрации участников, проверки накладных и любых задач, где нужно собрать много кодов подряд.

ВОЗМОЖНОСТИ
• Быстрое сканирование: код распознаётся сразу, без нажатия кнопки
• Таблица записей: номер, содержимое, тип кода, дата и время
• Экспорт в Excel (.xlsx) одним нажатием: отправьте файл на почту, в мессенджер или на облачный диск
• Фонарик для тёмных помещений
• Плавный зум ползунком для далёких или мелких кодов
• Защита от дублей: один и тот же код подряд не записывается дважды
• Поддержка QR и популярных штрихкодов (EAN, Code 128, Code 39, UPC, Data Matrix, PDF417, Aztec)
• Копирование содержимого записи нажатием на неё
• Современный интерфейс с тёмной темой

КОНФИДЕНЦИАЛЬНОСТЬ
Все данные хранятся только на вашем устройстве. Без регистрации, без рекламы, без отправки ваших записей на сервер. Камера используется только для считывания кодов.

КАК ПОЛЬЗОВАТЬСЯ
1. Разрешите доступ к камере.
2. Наведите камеру на QR-код: он появится в таблице.
3. Откройте вкладку «Таблица» и нажмите «Экспорт в Excel».
